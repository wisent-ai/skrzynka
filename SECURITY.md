# Security policy

Skrzynka handles credentials at a trusted local boundary and persists private message content. Do not place credentials, mailbox addresses, message bodies, provider identifiers, database files, or unredacted logs in a public issue.

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/wisent-ai/skrzynka/security/advisories/new). Include the affected source revision, operating system, observed boundary failure, and a minimal redacted reproduction description.

The development channel on `main` is the only maintained source until the first immutable release is published. There is no stable release line yet.
